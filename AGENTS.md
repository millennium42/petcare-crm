# PetCare CRM agent contract

- Work only inside this repository.
- Keep each agent inside its assigned directory/responsibility.
- Use the contracts in `docs/PRODUCT_SPEC.md` and `docs/API.md` as the shared truth.
- Do not add dependencies unless they remove more code than they introduce.
- Never commit `.env`, real personal data, credentials, build artifacts or dependencies.
- Security, authorization, LGPD and runnable checks are required; speculative abstractions are not.
- Final success requires tests, production builds, Docker health checks and an authenticated smoke test.
